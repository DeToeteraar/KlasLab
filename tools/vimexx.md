# Vimexx

## Wat
Domeinregistrar voor het beheren van domeinnamen.

## Wanneer gebruiken
Wanneer een project een eigen domein nodig heeft.

## Configuratie met Vercel
1. Koop of beheer het domein via [Vimexx](https://www.vimexx.nl)
2. Stel de DNS-records in om naar Vercel te wijzen:
   - A-record: `76.76.21.21`
   - CNAME: `cname.vercel-dns.com`
3. Voeg het domein toe in het Vercel dashboard
4. Vercel regelt automatisch het SSL-certificaat
